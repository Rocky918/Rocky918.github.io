4. 后台权限与发布流程

角色 可操作范围
产品负责人 全部配置页读写 + 发布 + 看板
运营 看板查看、部分文案建议（无发布权）
算法 拦截规则协同、效果数据查看
客服主管 高风险记录查看（只读）

发布流程： 配置修改 → 保存草稿 → 二次确认 → 发布生效 → 写操作日志。

5. 管理后台验收要点（补充）

  1. 主动关怀总开关关闭后，全站不再产生新的主动消息。
  2. 默认频率与勿扰变更后，新用户生效；老用户仍以个人设置为准。
  3. 拦截规则启停与提示文案修改后，C 端编辑记忆时行为符合预期。
  4. 看板数据与实际发送/关闭行为大致吻合（允许统计延迟）。
  5. 高风险记录可按时间查看，详情不含不当内容展示。
  6. 所有关键配置变更有操作人与时间日志。
